About Us

"anyshop" is the front facing e-commerce shop for COMP 3512 Assignment 2.

It is a single page html app built in javascript, swapping between the five main navbar views and uses the supplied .json data for all of the product information. The javascript code closely follows the efficient methods for displaying and working through similar functionalities shown in the labs and tutorials for COMP 3512.

Styling is done with Tailwind CSS inline styling in order to mimic modern e-commerce design trends (super minimal, compressed text, emphasis on the product images and information).

The github repo link can be found here: https://github.com/ntgarcia/comp3512a1

I, Nathan Garcia, am a BCIS student on my final semester for my degree. Aside from my studies I am currently doing freelance graphic design, web design as well as designing and overseeing the art direction for a clothing manufacturing company based in Los Angeles.
